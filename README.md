# 🎬 Movie API Web App

A modern movie browsing web app built using HTML, CSS, JavaScript and TMDB API.

## 🚀 Features

* Trending movies section
* Dynamic movie hero banner
* Movie popup with:

  * trailer
  * cast
  * movie details
  * similar movies
* Live movie search
* Pagination system
* Responsive design
* YouTube trailer support
* Clean Netflix-inspired UI

## 🛠️ Built With

* HTML5
* CSS3
* Vanilla JavaScript
* TMDB API
